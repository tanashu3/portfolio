ShockHold

Unity C# VR Blender Procedural Generation
Website

※左右にスライドして資料をご覧いただけます

体験動画 vol2.0.0（5月祭展示）

概要：4人チームで制作した、「夢中になれる射撃体験」を追求したVRシューティングゲーム。学園祭での展示にて好評を博しました。

Key Challenges & Solutions

  • 飽きさせない地形生成：固定マップによるマンネリ化や待機列からのネタバレを防ぐため、プレイごとに地形が変わる自動生成を実装。難易度（Easy/Hard）で複雑度が変化する仕組みも導入しました。
  • VR酔いの解消（UI）：視点移動とUIのズレによる酔いを防ぐため、UIが視線に「ゆっくり追従する」挙動を考案・実装。現実の感覚に近づけることで、没入感を維持しつつ酔いを大幅に軽減しました。

Implementation & Growth

これらの機能を可読性の高い500行のコードに凝縮して実装。展示会でのアンケート結果を基に改善を続ける中で、ユーザーの反応を分析しプロダクトを磨き上げる楽しさを学びました。

Game UI Design (Selection Task 1)

Figma Illustrator Photoshop UI Design

※左右にスライドして資料をご覧いただけます

概要：CyberAgent デザイナー選考課題にて制作したゲームUIデザイン。インターンシップでの経験を活かし、ツール習得からブラッシュアップまでを2週間で完遂しました。

Design Highlights & Analysis

  • Home: Diegetic UI（没入型UI）の採用
    既存の「ボタンを並べるだけのUI」ではなく、キャラクターの持ち物（本や道具など）をボタンとして機能させるデザインを構築。 これにより、前回の3D制作時に評価された「キャラクターとの疑似的なコミュニケーション体験」を、2DのUI画面においても損なうことなく再現しました。
  • Battle: 空間演出としての背景ギミック
    プレイヤーの後方視点（TPS視点）を採用して臨場感を演出。さらに、ボス登場時に「背景にある時計塔の窓を突き破って現れる」という演出を導入。 背景を単なる静止画として扱わず、戦闘の展開と連動する「ステージギミック」として機能させることで、画面全体を使った没入感を生み出しました。

Tools & Skills

  • Graphic Design (Ps/Ai): スチームパンクの世界観に合わせた質感（真鍮、革、ガラス）の表現とアセット作成。
  • Rapid Prototyping: 2週間という短期間でFigma、Illustrator、Photoshopを連携させた実務的なワークフローを確立。

Smartphone App Design (Selection Task 2) - "WeaLog"

Figma Illustrator Photoshop UI/UX Design

※左右にスライドして資料をご覧いただけます

概要：「天気でつながる、わたしの1日コーデ記録」をコンセプトにしたスマホアプリのUI/UXデザイン。「今日何着よう？」という実用的な悩みに対し、日記（記録）という情緒的な価値を掛け合わせた提案です。

UX Concept: 実用性 × 感情性

  • 課題解決（Utility）：気温や天候に合わせて、その場所に最適なコーディネートを提案。「寒いかな？」という毎朝の不安を解消します。
  • 情緒的価値（Emotion）：単なるツールで終わらせず、その日の服装と思い出を「カード」としてコレクションする楽しみ（Diary）や、SNSとしての共有性（Empathy）を設計の中心に据えました。

UI Design Highlights

  • Card UI Metaphor：毎日のコーデを「トレーディングカード」のように見せるデザインを採用。付箋（タグ）を用いた情報整理で、親しみやすさと視認性を両立しました。
  • Information Architecture：画面上部に天気情報（気温・降水確率）、下部にメインのコーデカードを配置。ロケーション（京都・東京・沖縄など）をスワイプで切り替える直感的な操作性を実現しています。
